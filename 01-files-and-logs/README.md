# Лабораторная №1. Файлы и анализ логов

## Задача

Подготовить структуру каталогов учебного приложения training-app,
проанализировать лог, сохранить результаты и создать резервную копию.

Работа выполнена на учебных данных. Настоящее приложение не запускалось.

## Окружение

- Windows 11
- Ubuntu 24.04 в WSL2
- Bash

## Подготовка

Из каталога лабораторной созданы каталоги:

```bash
mkdir -p app/config/
mkdir -p app/logs/
mkdir -p backups/
mkdir -p reports/
```

Ключ `-p` создаёт недостающие родительские каталоги.

Через nano подготовлены файлы:

- `app/config/app.conf` — учебная конфигурация;
- `app/logs/application.log` — учебный лог из 10 строк.

Структура проверена командой `ls -lR`, содержимое — командой `cat`.

У `ls`: `-l` — подробный вывод, `-R` — просмотр вложенных каталогов.

## Анализ лога

Все команды ниже выполнены из каталога лабораторной.

Подсчёт строк:

```bash
wc -l app/logs/application.log
```

Результат: 10 строк. Ключ `-l` у wc считает строки.

Поиск файлов с расширением .log:

```bash
find app -type f -name "*.log"
```

Результат: `app/logs/application.log`.

Параметр `-type f` выбирает обычные файлы,
`-name "*.log"` — имена, соответствующие шаблону.

Сохранение ошибок и предупреждений в отдельные файлы:

```bash
grep "ERROR" app/logs/application.log > reports/errors.txt
grep "WARNING" app/logs/application.log > reports/warnings.txt
```

Оператор `>` записывает вывод в файл, заменяя его прежнее содержимое.

Сохранение последних трёх строк:

```bash
tail -n 3 app/logs/application.log > reports/last-lines.txt
```

Ключ `-n 3` у tail задаёт количество последних строк.

Содержимое результатов проверено:

```bash
cat reports/errors.txt
cat reports/warnings.txt
cat reports/last-lines.txt
```

## Резервное копирование

Из каталога лабораторной выполнено:

```bash
cp -r app/ backups/
```

Ключ `-r` копирует каталог со всем его содержимым.
Копия находится в `backups/app`, исходный каталог сохранён.

Проверка копии:

```bash
ls -lR backups/app
cat backups/app/config/app.conf
cat backups/app/logs/application.log
wc -l backups/app/logs/application.log
```

Проверены структура и содержимое файлов. В скопированном логе 10 строк.
