# Лабораторная №6. Диагностика сетевых подключений

## Задача

Проверить сетевые интерфейсы, маршруты, доступность шлюза и внешнего
адреса, разрешение имён, DNS, TCP и HTTPS. Сделать выводы на основе
полученных результатов, отделяя подтверждённые факты от предположений.

## Окружение

- Windows 11, WSL2, Ubuntu 24.04.
- Сетевой интерфейс: eth0.
- IPv4-адрес: 172.21.122.223/20.
- Подсеть: 172.21.112.0/20.
- Шлюз по умолчанию: 172.21.112.1.
- Настроенный DNS-резолвер: 10.255.255.254.

Адреса указаны на момент выполнения проверок.

## Ход диагностики

1. Определены интерфейсы и адреса через `ip -br addr`.
2. Проверены таблица маршрутизации и маршрут к 1.1.1.1
   через `ip route` и `ip route get`.
3. Выполнены ICMP-проверки шлюза и внешнего адреса.
4. Проверено разрешение имени example.com через `getent`.
5. Проверены настройки резолвера и DNS-ответ через `dig`.
6. Проверено TCP-подключение к example.com на порт 443 через `nc`.
7. Выполнен HTTPS-запрос HEAD через `curl` с подробным выводом.

## Результаты

| Проверка | Результат |
|---|---|
| Маршрут к 1.1.1.1 | Через 172.21.112.1, интерфейс eth0 |
| ICMP к шлюзу | Ответы не получены: 4 запроса, 100% потерь |
| ICMP к 1.1.1.1 | Получены 4 ответа, потерь нет |
| Разрешение имени example.com | Получены два IPv4-адреса |
| DNS-запрос A | Получен ответ от настроенного резолвера |
| TCP к 172.66.147.243:443 | Соединение установлено |
| HTTPS к example.com | TLS 1.3, проверка сертификата успешна, HTTP/2 200 |

## Выводы

Отсутствие ICMP-ответов от шлюза не подтвердило его неисправность:
проверка внешнего адреса по выбранному маршруту прошла успешно.
Причина отсутствия ответов от самого шлюза не установлена.
Фильтрация ICMP остаётся предположением.

Успешная проверка TCP-порта через `nc` сама по себе не подтверждает
работу HTTPS. Отдельная проверка через `curl` подтвердила установление
TLS-соединения, успешную проверку сертификата и получение ответа
на HEAD-запрос. Получение тела страницы не проверялось.

Результаты относятся к проверенным направлениям и моментам выполнения
команд. Доступность остальных ресурсов сети не проверялась.
Изменения сетевой конфигурации не выполнялись.
