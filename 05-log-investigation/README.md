# Лабораторная №5. Расследование остановки службы по журналам Linux

## Задача

Выяснить, почему `lab-heartbeat.service` не работает и отключена
в автозапуске, а также проверить, связан ли этот статус с прежним
отказом запуска. Окружение: Ubuntu 24.04 в WSL2.

## Хронология

Время указано по Москве.

| Дата и время | Что установлено | Доказательство |
|---|---|---|
| 30 октября, 07:52:59 | Последняя найденная попытка запуска завершилась кодом `127`: Bash не нашёл скрипт по указанному пути. | [Журнал отказа и восстановления](reports/history-failure-recovery.txt) |
| 30 октября, 08:16:09 | После запуска появились регулярные сообщения скрипта. | [Журнал отказа и восстановления](reports/history-failure-recovery.txt) |

## Вывод

Исторический отказ с кодом `127` не объяснял исходное состояние
`inactive`: после отказа служба работала, а позже была остановлена
вручную. Контрольный запуск подтвердил работоспособность текущей
конфигурации без её изменения.
