# Linux Admin Lab

Учебные лабораторные работы по администрированию Linux.

В каждой работе описаны задача, выполненные действия,
использованные команды и проверка результата.

## Окружение

- Windows 11
- WSL2
- Ubuntu 24.04
- Bash

## План лабораторных работ

1. [Файлы и анализ логов](01-files-and-logs/README.md) — выполнено.
2. Пользователи и права доступа.
3. Управление процессами.

Работы будут добавляться по мере выполнения.
