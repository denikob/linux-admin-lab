# Лабораторная №3. Управление процессами Linux

## Задача

Запустить несколько фоновых процессов, определить их владельца,
PID и родительский процесс, изменить nice одного процесса
и завершить только выбранную задачу.

Работа выполнена на учебных процессах sleep в Ubuntu 24.04 через WSL2.

## Запуск процессов

В одной оболочке Bash запущены три фоновые задачи:

```bash
sleep 1800 &
sleep 1801 &
sleep 1802 &
```

Числа обозначают время ожидания в секундах.
Символ `&` запускает команду в фоновом режиме.

## Диагностика

Список задач текущей оболочки и их PID получен командой:

```bash
jobs -l
```

Ключ `-l` показывает дополнительную информацию, включая PID.

Для каждого процесса проверены PID, PPID, пользователь,
значение nice и команда с аргументами. Пример:

```bash
ps -p 1907 -o pid,ppid,user,ni,args
```

- `-p` — выбрать процесс по PID;
- `-o` — выбрать столбцы вывода;
- `ni` — значение nice;
- `args` — команда с аргументами.

В этом запуске родительским процессом всех трёх задач был Bash
с PID 315. Значения PID зависят от конкретного запуска.

## Изменение nice

У процесса `sleep 1801` с PID 1907 значение nice изменено с 0 на 10:

```bash
renice -n 10 -p 1907
```

- `-n 10` — задать значение nice 10;
- `-p` — указать PID процесса.

После изменения проверено: у выбранного процесса nice равно 10,
у двух остальных осталось 0.

## Завершение процесса

Перед завершением определён PID нужной задачи. Ей отправлен сигнал TERM:

```bash
kill -TERM 1907
```

Сигнал TERM запрашивает завершение процесса. После этого `jobs -l`
показал завершение выбранной задачи, а две другие оставались запущенными.

Команда `ps -p 1907` после завершения вывела заголовки без строки процесса.

## Вывод

Проверены владелец процессов, их PID, PPID и значение nice.
Значение nice одного процесса изменено, после чего выбранный процесс
завершён без завершения двух других учебных задач.

PID необходимо проверять перед отправкой сигнала: число `1801`
в `sleep 1801` — время ожидания, а не PID.

Подробный разбор находится в `reports/analysis.txt`.
