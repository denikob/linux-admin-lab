1. Пользователь labapp первоначально получал статус Permission denied при чтении файла app.conf в каталоге 
/opt/linux-admin-lab-permissions, потому что для данного файла право доступа на чтение было у группы 
labapp-readers в которую пользователь labapp не входил. Чтение было разрешено владельцу root и группе 
labapp-readers, а labapp не относится ни к одной из этих категорий.
2. Чтобы пользователь labapp смог читать файл, добавили его в группу labapp-readers с помощью команды usermod 
-aG labapp-readers labapp.
3. При том, права каталога linux-admin-lab-permissions имеющие значение 755 позволяли обращаться к файлу 
app.conf, потому что для других пользователей стоит правило 5 (4 + 1), где 1 разрешает обращаться к файлам 
внутри каталога. Сам каталог имеет пользователя и группу root:root, с правами 7 и 5, но это не мешает другим 
пользователями не входящим в группу root, обращаться внутрь каталога linux-admin-lab-permissions.
4. Мы добавили пользователся labapp в группу labapp-readers. Данная группа имеет права для файла app.conf только 
на чтение и ничего другого делать не позволяет.
5. Доступ постороненного пользователя проверил командой: sudo -u labother cat 
/opt/linux-admin-lab-permissions/app.conf. Получили статус Permission denied, то есть чтение запрещено.
6. Чтобы проверить, что пользователь не получил других доступов к файлу, я воспользовался командой: sudo -u 
labapp test -w /opt/linux-admin-lab-permissions/app.conf. Данная команда проверяет доступность файла для записи 
не изменяя его. Далее, чтобы получить результат данной команды используем команду: echo $?, где $? - это код 
завершения предыдушей команды, а echo выводит данный код на экран в терминал. В нашем случае мы получили 
значение 1, что говорит о том, что значение ложное, а значит пользователь не имеет права записывать данные в 
файл app.conf.

Решение соответствует принципу Least Privilege: labapp получил необходимое чтение конфигурации через группу 
labapp-readers. Запись ему недоступна, посторонний пользователь читать файл не может. Владелец и права файла 
остались прежними.
